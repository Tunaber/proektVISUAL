# proektVISUAL

Веб-приложение — табличный редактор (аналог Google Sheets/Excel) с поддержкой редактирования ячеек, формул, форматирования, контекстного меню, автосохранения и управления документами.

## Используемые инструменты

- **React 19** — UI-библиотека
- **TypeScript** — типизация
- **Vite** — сборщик и dev-сервер
- **Redux Toolkit** — управление состоянием (store, slices, async thunks)
- **React-Redux** — связка React с Redux
- **React Router** — маршрутизация
- **React Window** — виртуализация списков
- **TanStack React Virtual** — виртуализация строк/колонок таблицы
- **Vitest** — тестирование
- **Testing Library** — тестирование React-компонентов
- **ESLint** — линтер
- **Prettier** — форматирование кода
- **JSDOM** — окружение для тестов
